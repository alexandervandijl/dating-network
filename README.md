# Dating Network

Veilige datingsite voor singles op https://dating.alexandervandijl.nl/.

## Doel

Dating Network is gebouwd om mensen daadwerkelijk te helpen een passende relatie te vinden. De kernmatching blijft gratis; betaalde zichtbaarheid of matches achter een betaalmuur horen niet bij het model.

## Kernprincipes

- Alleen 18+ singles.
- Man ↔ vrouw.
- Geen externe contactgegevens of promotielinks.
- Eerst wederzijdse interesse, daarna interne chat.
- Uitlegbare matchscore.
- Veiligheid, blokkeren en rapporteren vanaf versie 1.
- Succes = iemand vinden en het platform niet meer nodig hebben.

De WordPress-plugin staat in de map `dating-network/`.
